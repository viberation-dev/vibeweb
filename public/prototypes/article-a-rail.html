Run Playwright MCP with Claude Code

Give your agent a real browser it can click, type and screenshot in — without handing it your logged-in Chrome profile.

Step 01What Playwright MCP actually gives you

Claude Code can read your files and run your commands. What it cannot do out of the box is look at the thing it just built. Playwright MCP closes that loop: the agent drives a real Chromium, reads the accessibility tree, and screenshots what it sees.

That matters for three jobs in particular — verifying a UI change, reproducing a bug report, and filling a form you would rather not fill by hand.

Note

MCP is a protocol, not a product. Playwright MCP is one server that speaks it; your editor is the client.

Step 02Install the server

One command, no global install.

bash
claude mcp add playwright -- npx -y @playwright/mcp@latest

Restart Claude Code and run /mcp. You should see playwright listed as connected.

Confirming it is live

Ask the agent to open a page and describe it. If it comes back with a structured list of headings and links rather than an apology, the server is wired up correctly.

Step 03Keep it out of your real browser

The default profile is isolated, and you should leave it that way. Pointing the server at your everyday Chrome profile hands an automated agent every session cookie you own.

Careful

Never pass --user-data-dir pointing at your daily browser profile. Log the agent in to a throwaway account instead.

The browser your agent drives should be one you would be comfortable handing to a stranger.
— Viberation security note

Step 04A first real task

Point it at your own dev server and ask for a verification pass rather than a click-by-click script. The agent plans the steps itself:

  • Verify — open localhost:3000/pricing, confirm the annual toggle updates all three cards.
  • Reproduce — paste the bug report, let it walk the steps.
  • Capture — screenshot the dashboard at mobile width, light and dark.

Step 05When to reach for something else

JobUseWhy
Verify your own UIPlaywright MCPFull control, isolated profile
Read one public pageFetchNo browser to start
Act inside your logged-in sessionBrowser extensionYou stay in the loop

Step 06Where to go next
